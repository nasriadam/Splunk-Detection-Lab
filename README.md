# Splunk Detection Lab

## Objective

The Splunk Detection Lab project aimed to build and configure a controlled Windows enterprise environment to collect, monitor, and analyze security events generated by different attack techniques.

The objective was to deploy an Active Directory domain infrastructure, centralize Windows security logs using Splunk Enterprise, enhance endpoint monitoring with Sysmon, and simulate attack scenarios in order to analyze and detect the resulting security events through a SIEM platform.

The lab environment includes:
- Windows Server 2022 as a Domain Controller
- Active Directory Domain Services (AD DS)
- DNS Server
- Windows 10 domain-joined client
- Ubuntu Server hosting Splunk Enterprise
- Splunk Universal Forwarder for Windows log collection
- Sysmon for enhanced endpoint monitoring
- Kali Linux for security testing and attack simulation
- Atomic Red Team for simulating MITRE ATT&CK techniques

---

## Skills Learned

- Deployment and configuration of Active Directory Domain Services.
- Configuration of DNS services for Active Directory.
- User, group, and computer account management.
- Joining Windows clients to an Active Directory domain.
- Installation and configuration of Splunk Enterprise.
- Configuration of Splunk Universal Forwarder for Windows event collection.
- Installation and configuration of Sysmon.
- Centralization and analysis of Windows security events.
- Analysis of Windows Event IDs, including failed authentication events (Event ID 4625).
- Simulation of attack techniques in a controlled laboratory environment.
- Use of Kali Linux tools for security testing.
- Use of Atomic Red Team to simulate MITRE ATT&CK techniques.
- Creation of SPL queries for security event investigation.
- Basic SIEM monitoring and security dashboard creation.
